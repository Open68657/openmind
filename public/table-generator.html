How to use the exports in InDesign & Illustrator
.idml → In InDesign: File ▸ Open the .idml. It opens as a new, untitled document with a fully native, editable table — change cells, strokes, fills, and use all the Table tools.
.idms → A snippet. Drag the file straight from Finder/Explorer onto an open InDesign layout (or File ▸ Place). The table drops in as a native table you can keep editing.
Fonts → InDesign renders with the font you named only if it is installed; otherwise it flags a missing font (text stays editable — just re-pick the font).
Illustrator → Illustrator has no native table object. Best path today: open the .idml in InDesign and copy/paste the table into Illustrator (it becomes editable text + vector strokes), or ask for a future SVG export.
